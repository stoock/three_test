# 거제동 골목길 1인칭 걷기 씬 — 설계 문서

날짜: 2026-06-10
참조 영상: `video/Screenshot 2026-06-10 at 22.00.03.webm` (네이버 지도 거리뷰 화면 녹화, 부산 연제구 거제동 여고로14번길, 23초, 1920x1080)

## 목표

참조 영상에 나오는 학교 옆 골목길 풍경을 Three.js 1인칭 걷기 씬으로 재현한다.
영상의 질감·텍스처(아스팔트, 화강암 석축, 시멘트 벽, 간판, 체크 타일)를 최대한 비슷하게 구현한다.

## 결정 사항

- **결과물 형태:** 1인칭 걷기 씬 (PointerLock + WASD)
- **텍스처 방식:** 혼합 — 기본 재질은 프로시저럴(캔버스 생성), 간판 등 특징적 요소는 영상 프레임에서 추출
- **씬 범위:** 영상 전체 경로 (학교 모퉁이 → 상가 골목 → 주택 골목 → 공사장/타일 입구)
- **아키텍처:** 모듈식 스트리트 키트 + 레이아웃 데이터 (A안)
- **작업 브랜치:** `feature/geoje-alley-walk` (main에서 분기)

## 파일 구조

```
index.html              — 진입점, 조작 안내 오버레이, WebGL 미지원 안내
vendor/three/           — 기존 브랜치(claude/yeouido-park-threejs-game-fvm993)에서 복사
                          three.module.js, PointerLockControls.js, Sky.js
assets/textures/        — 영상에서 ffmpeg로 크롭한 간판/타일 jpg
src/
  main.js               — 씬·렌더러·조명·게임루프 초기화, 모듈 조립
  player.js             — 1인칭 이동(WASD+마우스), AABB 충돌
  textures.js           — 프로시저럴 캔버스 텍스처 생성기
  layout.js             — 골목길 배치 데이터(구간별 건물/소품 위치·회전·크기)
  kit/
    street.js           — 도로·보도·경계석·노면표시("천천히", "학교앞", 노란선)
    buildings.js        — 범용 건물 생성기(층수·창문·간판 슬롯·옥상 파라미터)
    school.js           — 석축 옹벽 + 녹색 펜스 + 소나무 + 학교 건물
    props.js            — 전봇대+전선, 주차 차량, 표지판, 굴착기, 흙더미
```

각 kit 모듈은 `THREE.Group`을 반환하는 팩토리 함수를 내보낸다.
`layout.js`는 순수 데이터(JSON 형태의 배열)만 가지며, `main.js`가 데이터를 읽어 kit 팩토리를 호출해 배치한다.

## 씬 구성 (Z축 약 160m 골목)

| 구간 | 범위 | 내용 |
|------|------|------|
| 1. 학교 모퉁이 | 0–30m | 노란 현수막 게이트, 횡단보도, 곡선 펜스, 어린이보호구역 표지판 |
| 2. 상가 골목 | 30–80m | 우측 상가 건물열(수학학원 파란 간판, 매매 입간판), 좌측 학교 펜스, 택시·흰 세단 |
| 3. 주택 골목 | 80–120m | 양측 석축·흰 담장, 다세대주택, 주차 차량, 좌회전금지 표지 |
| 4. 종점 | 120–160m | 공사장(굴착기·흙더미·펜스), 어린이집, 적록 체크 타일 입구 모텔 |

좌측 전 구간: 화강암 석축 옹벽 위 녹색 철망 펜스 + 소나무, 뒤로 크림색 학교 건물 2동.
전봇대 6~8개, 전선은 catenary 곡선으로 연결.

## 텍스처 전략

**프로시저럴 (textures.js, 캔버스 기반):**
아스팔트(노이즈+균열), 화강암 석축 블록, 시멘트 스타코, 적벽돌, 녹색 철망(알파맵), 도로 페인트 마킹, 학교 창문 그리드

**영상 추출 (assets/textures/):**
수학학원 파란 간판, "매매" 빨간 입간판, 어린이집 외벽 장식, 적록 체크 타일, 원룸임대 현수막.
ffmpeg로 해당 프레임에서 크롭. 로드 실패 시 단색 머티리얼 폴백.

## 플레이어·조명

- PointerLockControls + WASD, 눈높이 1.6m, 걷기 4m/s, 달리기(Shift) 7m/s
- 건물·담장 AABB 목록과 충돌 검사, 골목 범위 밖 이동 차단
- 조명: DirectionalLight(그림자 캐스팅, 맑은 오후 각도) + Sky 셰이더 + HemisphereLight, ACES 톤매핑

## 오류 처리

- WebGL 미지원 시 index.html에서 안내 문구 표시
- 추출 텍스처 로드 실패 시 단색 머티리얼 폴백 (씬은 정상 동작)
- PointerLock 거부 시 클릭 안내 오버레이 유지

## 테스트·검증

- 로컬 정적 서버로 구동, 브라우저에서 수동 검증
- 검증 항목: 4개 구간 모두 도달 가능, 충돌 동작, 텍스처 표시, 콘솔 에러 없음, 60fps 근접
