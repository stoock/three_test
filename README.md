# 여의도 공원 산책 (Yeouido Park Walk)

Three.js 로 서울 여의도 공원을 스타일라이즈해 모델링한 1인칭 산책 게임입니다.
직접 걷고, 뛰고, 점프하며 공원 곳곳을 둘러볼 수 있습니다.

## 실행 방법

ES 모듈을 사용하므로 로컬 서버로 실행하세요.

```bash
# 방법 1: Python
python3 -m http.server 8000

# 방법 2: Node
npx serve .
```

브라우저에서 `http://localhost:8000` 접속 후 화면을 클릭하면 시작됩니다.
(Three.js 는 CDN 에서 불러오므로 인터넷 연결이 필요합니다.)

## 조작법

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| 마우스 | 시점 회전 |
| `Shift` | 달리기 (스태미나 소모) |
| `Space` | 점프 |
| `ESC` | 일시정지 |

## 둘러볼 곳

- **문화의 마당** — 넓은 포장 광장과 C-47 비행기 전시
- **잔디마당** — 세종대왕 동상이 있는 중앙 잔디밭
- **생태연못** — 육각정, 바위, 헤엄치는 오리들
- **한국전통의 숲** — 소나무가 우거진 동쪽 숲
- **자전거 도로 · 벚꽃길** — 공원을 한 바퀴 도는 트랙과 벚나무, 흩날리는 벚꽃잎
- 공원 너머로 보이는 여의도 스카이라인과 금색 **63빌딩**

## 기술

- [Three.js](https://threejs.org/) r160 (vendor 디렉토리에 포함, 빌드 불필요·오프라인 동작)
- `PointerLockControls` 기반 1인칭 시점
- **실사 지향 렌더링**
  - `Sky` 물리 기반 대기 산란 하늘 + 하늘을 PMREM 으로 구운 환경광/반사(IBL)
  - `Water` 셰이더 연못 — 주변 빌딩과 나무가 실시간 반사
  - ACES Filmic 톤매핑, 부드러운 그림자(PCFSoft), 거리 안개
  - 외부 이미지 없이 캔버스로 생성한 프로시저럴 텍스처: 잔디, 자갈길,
    보도블록, 우레탄 트랙, 나무껍질, 잎 디테일, 빌딩 유리창, 물 노멀맵
- 정점 지터로 울퉁불퉁하게 만든 유기적 수관 + 개체별 색 변화(`instanceColor`),
  나무 ~300그루 인스턴싱(`InstancedMesh`) 렌더링
- 원형 충돌체 기반 간단한 충돌 처리, 스태미나/점프/헤드밥 등 이동 메커닉
- 플레이어를 따라다니는 그림자 카메라로 넓은 맵에서도 선명한 그림자 유지
